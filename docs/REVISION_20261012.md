# Revision and evidence status — 2026-10-12

## Implementation changes

- Shared strict verifier JSON parser: genuine booleans only; malformed JSON,
  duplicate keys and non-string critiques fail closed. Symbolic, visual and global
  hypothesis verifiers use the same parser. The former `bool("false")` bug is fixed.
- Public flow loader for UNSW-NB15/CICIDS2017 with feature allowlists, partition
  checks, group-overlap rejection when supplied, duplicate removal, cleaning counts,
  hashes and reproducible memory/test sampling.
- Experiment 6: raw retrieval, first-proposal reflection, VLEG, raw-on-VLEG-admitted
  samples and global summary. Shared raw retrieval; labeled history; label-free
  target features. Strict output scoring and per-prediction checkpoint/resume.
- Configuration/data/code fingerprints and optional Ollama model digest recording;
  changed model/config/code/data cannot silently reuse a compatible-looking cache.
- Query latency and construction cost separately recorded. Embedding cost is not
  included in chat token accounting. Manual reflection-audit worksheet exported.
