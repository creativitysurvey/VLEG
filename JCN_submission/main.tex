\begin{abstract}
Verified Localized Episodic Grounding (VLEG) combines local reflection generation, verification against labeled historical episodes, and retrieval of reflections with source evidence. Five symbolic experiments examine consolidation, grounding and refinement at 7B and 70B model scales. An additional public-flow experiment evaluates five historical-memory seeds on the same 1,000 independently partitioned, deduplicated UNSW-NB15 records using a 70B model. VLEG improves Macro-F1 over unverified first reflections by 17.02 percentage points, but underperforms raw flow retrieval: 59.68\% versus 63.92\%. Attack recall increases from 71.39\% to 77.74\%, accompanied by a false positive rate increase from 38.13\% to 48.78\%. The paired conditional 95\% interval for the Macro-F1 difference is $[-5.91,-2.53]$ points. These results distinguish source-label checking and memory coverage from reliable downstream generalization. They support neither a universal hybrid-memory advantage nor operational intrusion-detection readiness. Historical symbolic numbers remain subject to provenance reconciliation; the completed flow experiment records exact model and source versions, prediction-level checkpoints and independently recomputed metrics.
\end{abstract}

\section{Introduction}
\subsection{Background: Retrieved Examples and Memory Consolidation}
Large language models can use retrieved examples to support classification and analysis without parameter updates \cite{brown2020language,lewis2020retrieval}. In network analysis, such examples could be labeled historical flow records or incident summaries. Their usefulness depends on retaining relevant context while avoiding unsupported conclusions. This paper studies that memory-design problem using controlled symbolic tasks and a separate public-flow benchmark; it does not establish performance on operational production networks.

Persistent memory separates stored experience from the model's finite prompt window \cite{packer2023memgpt,wang2023longmem,wang2024memoryllm}. Raw-example retrieval preserves evidence, while semantic consolidation compresses episodes into summaries or heuristics \cite{wu2025from,zhang2024survey}. Compression can reduce repeated reasoning but can also remove exceptions or introduce claims that the evidence does not support.

VLEG combines local reflection generation, verification against the originating labeled episode, and retrieval of the reflection with its raw evidence. We evaluate whether these operations improve label consistency, memory coverage and downstream accuracy, and report the circumstances in which they do not. Network-flow analysis is evaluated in a separate public benchmark experiment with frozen historical-memory seeds and held-out flow fingerprints.

\subsection{Problem Definition: Evidence and Context in Memory}
Raw examples can burden inference as the number and complexity of episodes increase \cite{an2024why,liu2024lost}. Local reflections offer compact guidance, but a reflection can contradict its source label or cite irrelevant attributes. Feedback-based systems such as Reflexion and Voyager already use evaluation to improve later behavior \cite{shinn2023reflexion,wang2024voyager}; our focus is the narrower decision of whether to admit an individual reflection into memory after checking it against its source episode.

A global summary can represent context-dependent rules, including the background-conditioned rule used in our experiments. Heterogeneity alone does not make global consolidation potentially difficult under a restricted summary budget. The practical question is whether summarization preserves relevant conditions and exceptions within the available evidence and context budget \cite{agarwal2026hypothesis,he2024idea}. Local and global memory therefore require empirical comparison rather than an assumed ordering.

\subsection{Verified Localized Episodic Grounding}
VLEG generates a candidate reflection from an episode's attributes and checks it against the complete historical episode, including its known label. Rejected candidates receive a critique and can be revised up to a fixed budget $K$. Only accepted candidates are stored. The generator and verifier are separate calls to the same underlying model, not statistically independent models.

At inference, VLEG retrieves memory tuples and provides the model with both raw episodes and their accepted reflections. This hybrid context may preserve evidence while supplying a compact heuristic, but its benefit is an empirical question. The five symbolic experiments compare memory strategies, grounding modalities, iteration budgets and reflection diagnostics at 7B and 70B model scales; a sixth experiment evaluates a controlled adaptation on public flow records. They show improved label consistency and memory coverage, alongside mixed downstream results and persistent unsupported attribution. These results establish boundaries of the evaluated implementation rather than universal correctness guarantees.

\section{Related Work}
\subsection{Episodic Memory and Retrieval}
In-context learning uses demonstrations in the prompt to support task adaptation without parameter updates \cite{brown2020language}. Retrieval-augmented generation connects generation to external evidence retrieved for the current input \cite{lewis2020retrieval}. LongMem extends access to past context through a memory bank and retrieval mechanism \cite{wang2023longmem}. These approaches make historical evidence available without requiring every experience to be converted into a rule. Their memory contents and training procedures differ, so they should not be treated as interchangeable implementations of a single memory architecture.

Retrieval studies address demonstration selection \cite{zhang2022active,purohit2025sample} and effective context length \cite{an2024why}, complementing broader surveys of memory design \cite{wu2025from,zhang2024survey}. These questions concern which evidence reaches inference, independently of whether that evidence is subsequently summarized.

For labeled classification tasks, raw-example retrieval offers a direct control: each historical record retains its observed features and label. It can preserve exceptions that a compressed summary omits, but its usefulness depends on selecting relevant examples within a finite context budget. A retrieved example also does not establish that a neighboring target has the same label. Retrieval relevance, evidence coverage and prediction correctness therefore require separate evaluation.

Our raw-memory baseline follows this evidence-preserving principle. It provides labeled historical episodes at inference without reflection-generation calls. The symbolic experiments compare it with abstract and hybrid context, while the public-flow experiment shares label-free feature retrieval across conditions to control example selection. This adaptation isolates the supplied memory content more closely than a comparison that changes both retrieval and context construction. It remains a controlled classification baseline, rather than a reproduction of the full training and retrieval procedures of the cited systems.

\subsection{Local Reflection and Feedback}
MemoryBank stores, retrieves and updates information from past interactions \cite{zhong2024memorybank}. Generative agents combine an experience store with higher-level reflections \cite{park2023generative}, while Reflexion converts task feedback into verbal reflections retained for subsequent trials \cite{shinn2023reflexion}. These works show several ways to use experience beyond storing raw examples. They differ in what constitutes an episode, which feedback is available, when memories are updated and how stored text influences later behavior.

Related work also examines procedural skill acquisition \cite{wang2024voyager}, structured agent memory \cite{xu2025amem}, and timeline-based memory management \cite{kim2024towards}. Their different memory objectives motivate explicit controls for the classification setting studied here.

The distinction between feedback and verification is especially relevant here. Feedback can identify an unsuccessful action or prediction and motivate revision. A source-episode check instead asks whether a candidate explanation agrees with the observed record under a specified prompt. Neither mechanism, by itself, proves that the resulting explanation identifies the correct causal factors. A reflection may repair its label while retaining an unsupported threshold or treating an incidental attribute as a general condition.

VLEG studies a bounded per-episode admission procedure: generate a candidate, check it against the labeled source, revise rejected candidates, and store an accepted reflection with its evidence. Historical labels are available to the check, whereas target labels are excluded from inference. We distinguish an unverified first proposal from a feedback-based multi-attempt comparator; these provide different opportunities for correction. Both are controlled adaptations, not complete reproductions of published agent systems. The evaluation consequently separates admission coverage and source-label agreement from explanation support and downstream generalization.

\subsection{Semantic Consolidation and Hybrid Grounding}
Semantic consolidation compresses experience into hypotheses or summaries that guide subsequent reasoning. Hypothesis-Driven Reasoning iteratively generates and verifies hypotheses against episodic evidence, then combines hypotheses with retrieved episodes at inference \cite{agarwal2026hypothesis}. It provides a close comparison for the unit of abstraction: hypotheses induced across episodes versus VLEG's reflections attached to individual source records. Global hypotheses can express conditional relations; indeed, one background-conditioned rule represents our synthetic environment. Heterogeneity alone therefore does not imply that global abstraction must fail.

Inductive reasoning and hypothesis generation are studied in \cite{he2024idea,kim2022playgrounds,lee2024generating,qiu2024phenomenal,zhou2024hypothesis}; complementary work considers memory architectures \cite{kim2023machine,li2024memory,wang2025mirix} and iterative feedback or critique \cite{madaan2023selfrefine,gou2024critic}. We compare these research directions through abstraction scope, correction signals and inference evidence.

Hybrid grounding supplies both an abstraction and supporting examples. This retains access to concrete evidence, but can introduce conflicting guidance when the abstraction is inaccurate or applies too broadly. Its effectiveness depends on the content and applicability of the reflection, not merely the presence of both memory types. Comparing raw, abstract and hybrid context is necessary to identify these trade-offs.

VLEG's contribution is a controlled assessment of local admission checking and evidence--reflection pairing, including their limitations. The public-flow evaluation also includes raw retrieval restricted to admitted episodes, helping distinguish admission from reflection content. We report balanced classification, attack recall, false alarms and construction cost rather than inferring utility from memory coverage alone. These comparisons test when verified local memory is useful without assuming a universal advantage over direct retrieval or global consolidation.

\section{The Proposed Method}
\label{sec:vleg-methodology}
\subsection{Overview of Verified Localized Episodic Grounding (VLEG)}
VLEG stores a labeled historical episode with an accepted local reflection. The implementation distinguishes generation, checking and inference roles. The following formulation describes their information access and stopping behavior; it does not guarantee correctness of the verifier or general validity of an accepted rule.

Let $\mathcal{E}=\{e_1,\ldots,e_n\}$ be historical episodes whose labels are available during consolidation. A pure episodic memory stores those labeled episodes directly. In the measured experiments, episodes are symbolic scene tuples. A network-flow implementation instead requires actual flow features and an independently labeled historical partition. Test labels are excluded from inference in either setting.

Conversely, global semantic consolidation \cite{agarwal2026hypothesis} attempts to distill $\mathcal{E}$ into a compact set of universal rules or hypotheses, $\mathcal{H}$. This can be modeled as finding a global hypothesis set that maximizes the likelihood of the observed episodes:
\begin{equation}
    \mathcal{H}^* = \arg\max_{\mathcal{H}} P(\mathcal{H} \mid e_1, e_2, \dots, e_n)
\end{equation}
A single conditional hypothesis can represent the contextual rule used here. In other datasets, a limited-length summary may omit important exceptions. This is a capacity and evidence question, not a consequence that follows from heterogeneity alone.

VLEG bridges this gap by shifting the abstraction target from the global distribution to the localized episode, while enforcing strict logical verification. Rather than attempting to find a universal $\mathcal{H}^*$, VLEG constructs a memory bank consisting of verified episodic-semantic tuples:
\begin{equation}
    \mathcal{M}_{VLEG} = \left\{ (e_i, r_i^*) \mid e_i \in \mathcal{E}, \; \mathcal{V}(r_i^* \mid e_i) = 1 \right\}
\end{equation}
where $r_i^*$ is a localized semantic reflection (a detection rule or heuristic) derived specifically from episode $e_i$, and $\mathcal{V}(\cdot \mid e_i)$ is a strict verification function that returns $1$ when the implemented verifier accepts the candidate under its checking prompt; acceptance is a model judgment and can be wrong.

\subsection{Framework Components: Generator, Verifier, and Memory Bank}
The implementation has a reflection generator, a verifier and a memory bank. Generation and checking use separate prompts and model calls. They use the same underlying model, so shared errors and dependent responses remain possible.

\subsubsection{The Reflection Generator ($\mathcal{G}_\theta$)}
The Reflection Generator is an LLM parameterized by $\theta$, tasked with distilling a high-dimensional raw traffic episode $e_i$ into a localized, natural language abstraction $r_i$. Formally, at iteration $j=0$, the generator samples an initial candidate reflection conditioned solely on the raw episode:
\begin{equation}
    r_i^{(0)} \sim \mathcal{G}_\theta(\cdot \mid e_i)
\end{equation}
In subsequent iterations ($j > 0$), if the initial reflection is deemed invalid, the generator is conditioned on the raw episode, its previous candidate reflection $r_i^{(j-1)}$, and a natural language critique $c^{(j-1)}$ provided by the verifier:
\begin{equation}
    r_i^{(j)} \sim \mathcal{G}_\theta(\cdot \mid e_i, r_i^{(j-1)}, c^{(j-1)})
\end{equation}
While systems like Reflexion \cite{shinn2023reflexion} terminate after generating $r_i^{(0)}$ and immediately commit it to memory, VLEG treats $\mathcal{G}_\theta$ strictly as a proposal distribution whose outputs are inherently untrusted until validated.

\subsubsection{The Strict Verifier ($\mathcal{V}_\phi$)}
The verifier checks the candidate against one labeled historical episode. It can reject a mismatched label, an invented attribute or an uncheckable claim. This role is distinct from generation, but the two calls are not statistically independent.

The verifier outputs a tuple consisting of a binary validity score $v^{(j)} \in \{0, 1\}$ and a diagnostic critique $c^{(j)}$:
\begin{equation}
    (v^{(j)}, c^{(j)}) = \mathcal{V}_\phi(e_i, r_i^{(j)})
\end{equation}
If $v^{(j)}=1$, the candidate passes the implemented admission check. If $v^{(j)}=0$, its critique is returned to the generator. Admission establishes only that this verifier accepted the reflection for this episode; it does not certify a universal rule or a lower false-positive rate than another system.

\subsubsection{The Hybrid Memory Bank ($\mathcal{M}$)}
Once a reflection successfully passes the verifier (i.e., $v^{(j)} = 1$), it is denoted as the verified reflection $r_i^*$. The Hybrid Memory Bank $\mathcal{M}$ stores the paired tuple of the raw episode and its verified abstraction:
\begin{equation}
    \mathcal{M} = \bigcup_{i=1}^{N} \left\{ (e_i, r_i^*) \mid \exists j \le K \text{ s.t. } \mathcal{V}_\phi(e_i, r_i^{(j)})_v = 1 \right\}
\end{equation}
where $K$ is the maximum allowed refinement iterations. If an episode fails to yield a valid reflection within $K$ iterations, it is discarded to preserve memory integrity.

The memory bank supports retrieval of both source evidence and a local reflection. This is the representation used in the hybrid modality; raw-only and abstract-only inputs remove one of its components for comparison.

\subsection{Learning Mechanism: Iterative Cyclic Refinement}
The refinement loop revises a rejected candidate using the verifier critique. It stops at the first accepted candidate or after $K$ attempts. Reaching the budget without acceptance discards the episode from this reflection memory.

Formally, let $e_i \in \mathcal{E}$ denote a raw, high-dimensional traffic episode. The refinement process is governed by two interacting models: the Reflection Generator $G_\theta$ and the Strict Verifier $V_\phi$. At the initial iteration ($j=0$), the generator produces a candidate reflection conditioned solely on the raw episode:
\begin{equation}
    r_i^{(0)} \sim G_\theta(\cdot \mid e_i)
\end{equation}
Once a candidate reflection $r_i^{(j)}$ is generated, it is passed to the verifier $V_\phi$. The verifier acts as a deterministic logical gate, evaluating the reflection strictly against the grounding evidence $e_i$. It outputs a tuple consisting of a binary validity score $v_i^{(j)} \in \{0, 1\}$ and a natural language critique $c_i^{(j)}$:
\begin{equation}
    (v_i^{(j)}, c_i^{(j)}) = V_\phi(e_i, r_i^{(j)})
    \label{eq:verifier}
\end{equation}
Note that $V_\phi$'s only argument besides the candidate reflection is the single episode $e_i$ it was generated from --- by construction it has no access to any other episode. This can expose a reflection that misstates $e_i$'s own attributes or label, but not sufficient to determine whether an attribute the reflection treats as necessary is actually causally relevant across episodes versus merely true of this one instance. This defines a key boundary condition of the verifier, which we investigate empirically in Experiment 5 (Section~\ref{sec:exp5}).

If $v_i^{(j)} = 1$, the reflection is deemed valid, the loop terminates, and the verified reflection $r_i^* = r_i^{(j)}$ is committed to the memory bank. If $v_i^{(j)} = 0$, the reflection contains a logical inconsistency or hallucination. The critique $c_i^{(j)}$ is then fed back into the generator to produce a refined reflection for the next iteration:
\begin{equation}
    r_i^{(j+1)} \sim G_\theta(\cdot \mid e_i, r_i^{(j)}, c_i^{(j)})
\end{equation}
This process repeats until either $v_i^{(j)} = 1$ or a maximum iteration limit $K$ is reached. If the limit $K$ is exhausted without validation, the episode is deemed too ambiguous, and no reflection is stored, thereby prioritizing memory precision over recall.

\begin{remark}[Scope of the admission check]
Let $A_j$ denote reaching attempt $j$, $E_j$ an erroneous candidate at that attempt, and $B_j$ its acceptance by the verifier. For $j=1,\ldots,K$, suppose
$\Pr(E_j\mid A_j)\leq p_h$ and
$\Pr(B_j\mid A_j,E_j)\leq p_v$ for a specified error class.
Since the loop stores the first accepted candidate,
\begin{equation}
\begin{aligned}
\Pr(\text{erroneous commitment})
&\leq \sum_{j=1}^{K}\Pr(A_j\cap E_j\cap B_j)\\
&\leq \min\{1,Kp_hp_v\}.
\end{aligned}
\end{equation}
This union bound needs no independence assumption. It does not imply that increasing $K$ reduces erroneous commitments, nor does it bound error conditional on admission. A geometric power of $p_v$ would require repeated acceptance checks on the same candidate, which the implemented loop does not perform. The probabilities are not estimated by the present experiments.
\end{remark}
A single labeled episode can expose a contradiction or a fabricated attribute, but cannot establish which attributes cause a label or whether a heuristic transfers to other episodes. Experiment 5 measures this distinction in the symbolic setting; public-flow explanations require additional cross-episode or human assessment.

\subsection{Inference Integration: Hybrid Episodic-Semantic Grounding}
Once the memory bank $\mathcal{M} = \{(e_i, r_i^*)\}_{i=1}^N$ has been populated with accepted tuples through the iterative cyclic refinement process, the system must effectively leverage this knowledge to solve a novel target task $T$ (e.g., classify a held-out flow or an unseen feature combination). Traditional retrieval-augmented generation (RAG) and standard in-context learning paradigms predominantly rely on episodic-only retrieval \cite{lewis2020retrieval, zhang2022active}, injecting raw, unstructured experiences directly into the context window. While this preserves high-fidelity details, it forces the reasoning module to perform ad-hoc abstraction at test time, which frequently leads to cognitive overload and degraded performance in complex, multi-source traffic environments.

To overcome this limitation, VLEG introduces a dual-pathway integration strategy termed \textit{Hybrid Episodic-Semantic Grounding}. This approach simultaneously injects the raw telemetry $e_i$ and its corresponding verified semantic rule $r_i^*$ into the context window, aligning with advanced memory integration paradigms that advocate for structured, multi-level memory representations \cite{wu2025from, zhang2024survey}. Our empirical evaluations further characterize the \emph{task- and scale-dependent boundary conditions} where hybrid grounding yields advantages versus when alternative grounding modalities perform comparably or better.

\subsubsection{Semantic-Driven Retrieval}
Given a novel target task $T$, the system must first retrieve the top-$k$ most relevant memory tuples. Because the raw episodes $e_i$ are high-dimensional and often contain task-irrelevant noise, VLEG performs retrieval primarily in the semantic space defined by the verified reflections $r_i^*$.

Let $\phi(\cdot)$ denote a pre-trained dense embedding function. The relevance score $S(T, \mathcal{M}_i)$ for a given memory tuple $\mathcal{M}_i = (e_i, r_i^*)$ is computed using the cosine similarity between the embedding of the target task and the embedding of the verified reflection:
\begin{equation}
    S(T, \mathcal{M}_i) = \frac{\phi(T) \cdot \phi(r_i^*)}{\|\phi(T)\| \|\phi(r_i^*)\|}
\end{equation}
The system then selects the subset of $k$ tuples that maximize this similarity score:
\begin{equation}
    \mathcal{M}_{top} = \mathop{\arg\max}_{\mathcal{S} \subset \mathcal{M}, |\mathcal{S}|=k} \sum_{(e_i, r_i^*) \in \mathcal{S}} S(T, (e_i, r_i^*))
\end{equation}

\subsubsection{Hybrid Prompt Formulation}
After retrieving $\mathcal{M}_{top}$, the inference module constructs a hybrid context window. The fundamental premise of hybrid grounding is that the verified reflection $r_i^*$ provides the abstract, logical scaffold (the ``what'' and ``why''), while the raw episode $e_i$ provides the concrete, high-dimensional grounding (the ``how''). This permits comparison with the source evidence, but does not guarantee that unsupported generalization is avoided.

The final inference prompt $P$ is constructed by concatenating the target task $T$ with the retrieved hybrid tuples, separated by structural delimiters:
\begin{equation}
\begin{aligned}
    Q_i &= \big[\text{Episode: }e_i \oplus \text{Verified Rule: }r_i^*\big],\\
    P &= \text{PromptBuilder}\Bigl(
    \bigoplus_{(e_i,r_i^*)\in\mathcal{M}_{top}} Q_i
    \oplus \text{Target: }T\Bigr).
\end{aligned}
\end{equation}
where $\oplus$ denotes the sequence concatenation operator. The reasoning LLM, parameterized by $\theta$, then generates the final prediction $\hat{y}$ conditioned on this hybrid prompt:
\begin{equation}
    \hat{y} = \text{LLM}_\theta(P)
\end{equation}

Hybrid context provides a reflection and its source evidence. Its benefit depends on whether the reflection guides the model toward relevant attributes or anchors it on a misleading condition. Experiment 2 compares hybrid, raw-only and abstract-only inputs under shared retrieval.

\subsection{Final Algorithm and Execution Flow}
The Verified Localized Episodic Grounding (VLEG) framework synthesizes the previously defined components---the Reflection Generator $G_\theta$, the Strict Verifier $V_\phi$, and the Hybrid Inference Module $I_\psi$---into a cohesive, end-to-end execution pipeline. This pipeline systematically bridges the gap between raw episodic retention \cite{brown2020language} and abstract semantic reasoning \cite{agarwal2026hypothesis} by ensuring that only accepted local heuristics are utilized during downstream inference.

The execution flow of VLEG is formally divided into two distinct phases: \textbf{Phase 1: Memory Consolidation} and \textbf{Phase 2: Hybrid Inference}.

During Phase 1, the system ingests a stream of raw, high-dimensional traffic episodes $\mathcal{E} = \{e_1, e_2, \dots, e_n\}$. For each episode $e_i$, the Generator $G_\theta$ proposes an initial candidate reflection $r_i^{(0)}$. The Verifier $V_\phi$ then evaluates this candidate strictly against the grounding episode $e_i$, outputting a binary validity flag $v \in \{0, 1\}$ and a natural language critique $c$. If $v = 0$ (indicating a label-level hallucination or logical inconsistency), the critique $c$ is fed back into $G_\theta$ to produce a refined reflection $r_i^{(1)}$. This iterative cyclic refinement continues until the reflection is validated ($v=1$) or a predefined maximum iteration limit $K$ is reached. If validated, the tuple $(e_i, r_i^*)$ is committed to the Memory Bank $\mathcal{M}$. This strict gating mechanism bounds the propagation of unverified heuristics for label-contradiction errors, directly addressing the vulnerabilities of single-step reflection pipelines \cite{shinn2023reflexion}.

During Phase 2, the system is presented with a novel target task $T$. A Retriever $R$ computes the cosine similarity between the task embedding and the stored memory tuples, extracting the top-$k$ most relevant memories $\mathcal{M}_{top} \subset \mathcal{M}$. The Inference Module $I_\psi$ is then prompted using Hybrid Episodic-Semantic Grounding, receiving both the raw episodes and their verified reflections to generate the final output. This dual-pathway integration aligns with advanced memory paradigms \cite{wu2025from}, making both representations available for the evaluated inference conditions.

The complete step-by-step procedure is formalized in Algorithm \ref{alg:vleg_final}.

\begin{algorithm*}[!t]
\caption{Verified Localized Episodic Grounding (VLEG)}
\label{alg:vleg_final}
\small
\begin{algorithmic}[1]
\Require Episodic stream $\mathcal{E} = \{e_1, \dots, e_n\}$, Target Task $T$, Max Iterations $K$, Retriever $R$
\State Initialize Memory Bank $\mathcal{M} \gets \emptyset$
\State \textbf{// Phase 1: Memory Consolidation}
\For{each $e_i \in \mathcal{E}$}
    \State $j \gets 0$
    \State $c \gets \emptyset$ \Comment{Initialize empty critique}
    \State $v \gets 0$ \Comment{Initialize validity flag to Invalid}
    \While{$v = 0$ \textbf{and} $j < K$}
        \State $r_i^{(j)} \gets G_\theta(e_i, c)$ \Comment{Generate or refine reflection}
        \State $(v, c) \gets V_\phi(e_i, r_i^{(j)})$ \Comment{Verify reflection against raw episode}
        \State $j \gets j + 1$
    \EndWhile
    \If{$v = 1$}
        \State $\mathcal{M} \gets \mathcal{M} \cup \{(e_i, r_i^{(j-1)})\}$ \Comment{Store verified tuple}
    \EndIf
\EndFor
\State \textbf{// Phase 2: Hybrid Inference}
\State $\mathcal{M}_{top} \gets R(\mathcal{M}, T, k)$ \Comment{Retrieve top-$k$ relevant tuples}
\State $\text{Context} \gets T \cup \mathcal{M}_{top}$ \Comment{Construct hybrid prompt}
\State $\text{Output} \gets I_\psi(\text{Context})$ \Comment{Generate final reasoning answer}
\State \Return $\text{Output}$
\end{algorithmic}
\end{algorithm*}



The admission gate prevents storage when the verifier rejects a candidate. Its practical reliability depends on the verifier and the error class being checked. Retaining raw evidence permits downstream comparison with a reflection, but does not ensure that the model performs that comparison correctly.


\section{Experiments}

\subsection{Experimental Settings}
Experiments 1--5 use synthetic scenes with shape, color, texture, background and a deterministic size distractor. On white backgrounds, ANOMALY requires a red circle; black backgrounds invert this rule. Texture and size are noncausal. Level 1 contains eight white-background combinations; Level 2 contains sixteen across both backgrounds. Both evaluate combinations used to form memory. Level 3 withholds four from memory and tests all sixteen; masked-only accuracy measures withheld-combination generalization. Seeds change the withheld subset, not the underlying population.

Reported symbolic runs use Qwen2.5-7B-Instruct or Llama-3.3-70B-Instruct, nomic-embed-text embeddings and temperature $0$. Generator and verifier are separate calls to the same model. Generation excludes historical labels; verification receives labeled source episodes, so refinement uses supervised feedback. Target labels are reserved for scoring. We vary consolidation, grounding modality and $K\in\{1,2,3,5\}$, measuring accuracy, memory coverage, label consistency, attribution flags and construction tokens. Experiment 2 shares retrieval across modalities. First-proposal reflections, feedback-based Reflexion and global hypotheses are controlled adaptations; their implementation differences are identified below.

The 7B and latest 70B archives have been reconciled, but lack original verifier replies and exact model digests. They precede strict boolean-parser repairs and were not rerun. Cross-scale comparisons also change model family and cannot isolate parameter count. Repeated queries across seeds are not independent samples, and temperature $0$ does not guarantee identical outputs. Experiment 6 separately specifies the public-flow data, frozen model versions, split, metrics and runtime costs.

\subsection{Experiment 2: Component Isolation (Grounding Modality Ablation)}
\label{sec:exp2}

Experiment 2 isolates which retrieved content is shown to the inference model: the raw episode, the accepted reflection, or both. The same retrieved tuples are used across conditions to reduce retrieval-quality confounding.

To achieve this, we evaluate the framework under three distinct ablation conditions. The first condition is \textit{Hybrid Grounding (VLEG)}, which represents the complete proposed methodology where the reasoning module is conditioned on both the retrieved raw episodes $e_i$ and their corresponding verified reflections $r_i^*$. The second condition is \textit{Abstract-Only Grounding}, where the reasoning module is provided solely with the verified reflections $r_i^*$, completely omitting the raw traffic episodic data. The third condition is \textit{Raw-Only Grounding}, which serves as a baseline mirroring standard In-Context Learning (ICL) \cite{brown2020language}, where the model receives only the raw episodes $e_i$ without any distilled semantic guidance.

To isolate the effect of grounding \emph{content} from retrieval quality, all three conditions retrieve the same top-$k$ memory tuples (via cosine similarity on the verified reflection's embedding, as VLEG's memory bank is built the same way regardless of which fields are shown at inference); only which fields of each retrieved tuple are shown to the reasoning LLM differs between conditions.

The measured results, shown in Figure \ref{fig:exp2_ablation}, do not match the hypothesized ordering. On Level 2 (no masking), Hybrid Grounding is indeed the best condition (87.5\% vs.\ 81.2\% for both alternatives). But on Level 3 --- the condition this experiment was specifically designed to stress-test --- the ordering inverts: Hybrid Grounding is the \emph{worst} of the three conditions, both overall (73.8\% pooled across 5 masking seeds, $n=80$, vs.\ 78.8\% for Abstract-Only and 75.0\% for Raw-Only) and specifically on the masked combinations that never appeared during memory formation (60.0\% pooled, $n=20$, vs.\ 70.0\% for both alternatives). Hybrid never outperformed both alternatives on Level 3 in any of the 5 seeds tested. We connect this to Experiment 5 (Section~\ref{sec:exp5}): verified reflections frequently cite causally irrelevant attributes as if they were determinative (see the empirical caveat in Section~\ref{sec:vleg-methodology}), and pairing a raw episode with such a reflection appears to anchor the reasoning model on the reflection's stated --- sometimes spurious --- condition rather than letting it reason more freely from the raw examples, which is more costly precisely when generalization to an unseen combination is required.

\subsection{Experiment 3: Iterative Refinement Ablation}
\label{sec:exp3}

Experiment 3 tests whether increasing the refinement budget recovers rejected episodes and changes prediction accuracy. It does not assume that iteration or verification is necessary in every task.

Both $K=1$ and $K=3$ run the same generate-and-verify procedure. At $K=1$, the one rejected proposal leads to discarding the episode; at $K=3$, the generator can revise after critique. This is a refinement-budget ablation, not a verified-versus-unverified comparison. Both use the same model and hybrid inference.

Across five masking seeds, $K=3$ achieves $75.0\%$ overall accuracy ($60/80$) versus $63.75\%$ ($51/80$) for $K=1$, a difference of $11.25$ percentage points. Masked-only accuracy is $60.0\%$ ($12/20$) versus $50.0\%$ ($10/20$). The masked-only difference is zero in three seeds and positive in two. These counts are repeated evaluations under different memory masks, not eighty independent scenes.

The mechanism behind the gain is memory bank \emph{coverage}, not reasoning quality per reflection: across the 5 seeds, $K=1$'s memory bank retained only $42$--$58\%$ of training episodes (an episode whose first-guess reflection is rejected is discarded outright, since $j$ is never $<K{=}1$ again), while $K=3$'s retained $83$--$100\%$, because the critique from a rejected first attempt typically reveals the correct label and lets the generator correct itself on the second or third try. Verification at $K=3$ is thus better understood here as \emph{recovering episodes that a single unlucky guess would otherwise lose}, not as improving the causal quality of the reflections that do get committed --- see Experiment 5 (Section~\ref{sec:exp5}) for a direct measurement showing no such quality improvement.

\textbf{Cross-scale check.} At 70B, the reported mean overall difference is $26.2$ percentage points (standard deviation $8.1$) across the same five seeds, and $K=3$ admits all twelve historical episodes in each seed. The results are consistent with coverage recovery through label-informed critique; they do not show that the accepted explanations identify causal attributes more reliably.

\subsection{Experiment 4: Parameter Sensitivity and Overhead Analysis}
\label{sec:exp4}

The primary objective of Experiment 4 is to systematically analyze the convergence behavior of the VLEG verification loop and to quantify the associated computational trade-offs. While the iterative generate-and-verify mechanism is designed to strictly filter out hallucinated heuristics, each refinement cycle inherently incurs additional computational costs during the memory consolidation phase. Therefore, it is critical to evaluate how the strictness of the verification process impacts both the downstream reasoning performance and the overall token efficiency of the system.

To conduct this sensitivity analysis, we manipulate the maximum refinement iterations parameter, $K$, across a discrete set of values: $K \in \{1, 2, 3, 5\}$. The condition $K=1$ effectively disables the iterative refinement loop, reducing the system to a single-step reflection generator akin to standard localized reflection baselines \cite{shinn2023reflexion}. For each configuration of $K$, we evaluate the model on both Level 2 and Level 3 of the Experience-Transfer task. We record the resulting Task Accuracy (\%) alongside the Computational Overhead, which is measured as the total number of prompt and completion tokens consumed per consolidated episodic memory.

The measured results, shown in Figure \ref{fig:exp4_sensitivity}, contradict both claims originally hypothesized for this experiment. First, Task Accuracy does not plateau around $K=3$. On Level 2 --- a single run, verified deterministic by an exact repeat --- accuracy keeps climbing substantially from $K{=}3$ ($87.5\%$) to $K{=}5$ ($93.8\%$), a further $+6.3$ point gain with no sign of leveling off in this range. On Level 3, we tested 3 independent masking seeds: only one of them ($\text{seed}=42$) shows the exact plateau signature (identical bank composition, token count, and accuracy at $K{=}3$ and $K{=}5$); the other two show $K{=}5$ either matching or beating $K{=}3$ by a further $+6$--$12.5$ points. We do not have a reliable stopping criterion at $K=3$ in this environment --- it happens to be sufficient for some random draws of the masked subset and insufficient for others.

Second, Computational Overhead does not scale linearly with $K$. It is concave: the token cost per consolidated episode rises sharply from $K{=}1$ to $K{=}2$ ($+279$ tokens/episode on Level 2) and then far more slowly for each additional unit of $K$ budget ($+71$ tokens/episode from $K{=}2$ to $K{=}3$, $+35$ from $K{=}3$ to $K{=}5$ despite that step covering two extra iterations, not one). This pattern was consistent across all seeds tested on both levels. The mechanism is straightforward: most episodes converge within 1--2 iterations regardless of the ceiling $K$; raising the ceiling only adds cost for the small minority of episodes that are still unresolved at iteration 3, so the marginal cost of a higher $K$ budget shrinks as $K$ grows even as the marginal \emph{benefit} (per the accuracy panel) does not reliably shrink in the same way. Practitioners should not treat $K=3$ as a validated efficiency-optimal cutoff on the basis of this experiment; whether a higher $K$ is worth its (modest, sub-linear) additional cost depends on how much the specific downstream task benefits from the extra recovered episodes, which Experiment 3 (Section~\ref{sec:exp3}) suggests is real but seed-dependent in magnitude.

\textbf{Cross-scale check.} At 70B, the reported Level-3 sweep uses three masking seeds. In each, $K=2$, $K=3$ and $K=5$ yield the same admitted memory, token consumption and accuracy. No episode needs a third attempt in these runs. The observed plateau is therefore at $K=2$ in this model and task, while the 7B sweep is less uniform. This does not establish a universal stopping budget.

Concurrent GPU workloads make the affected timing measurements unsuitable for a clean overhead comparison. One reported repeat at Level 2, $K=3$, changes the token count from $12{,}541$ to $12{,}625$ while preserving accuracy. Accordingly, temperature $0$ is recorded as a decoding setting, and repeatability and hardware contention must be assessed empirically for each run.

\subsection{Experiment 6: Public-Flow Benchmark Validation}
\label{sec:exp6}
This experiment tests whether local verification and hybrid memory improve classification of independent public flow records. It uses UNSW-NB15, a captured testbed benchmark containing normal and generated attack traffic \cite{moustafa2015unsw}. It is not a production deployment or zero-day detection study. The completed archive contains 500 pilot predictions and 25,000 formal predictions; an offline audit reproduces the metrics, conditional bootstrap intervals and construction-cost totals from the stored records.

\textbf{Data and partition audit.} The source partitions contain 175,341 historical and 82,332 test records. The frozen feature representation uses nineteen fields: duration, protocol, service, state, directional packet and byte counts, rate, TTL, load, inter-packet timing, jitter and mean packet size. IPs, timestamps, row identifiers, attack names and target labels are excluded from model inputs and retrieval keys. The public mirror is pinned to a commit; its file names are reversed relative to the official partition sizes, so role mapping is recorded explicitly and checked by row count, size, MD5 and SHA256. Bytes agree with an independent research deposit, although the original author-hosted files were not directly accessible.

Identical selected-feature vectors sometimes have conflicting labels. We exclude every row in such groups rather than choosing a label: 6,896 historical rows in 273 groups and 2,912 test rows in 105 groups. We also remove 79,746 and 33,161 remaining same-label duplicate rows, respectively, leaving 88,699 historical and 46,259 test fingerprints. A further 1,044 test fingerprints overlap the cleaned historical source and are excluded. Thus the evaluated population is deduplicated and unambiguous in this representation; removing these cases can change difficulty and class balance, so these results do not estimate performance on the original flow-frequency distribution. Session-level independence cannot be established because this partition lacks session-group metadata.

\textbf{Frozen evaluation and implementation.} Each of five memory seeds (20261020--20261024) selects sixteen benign and sixteen malicious historical examples. They share the same 1,000 test fingerprints: 663 benign and 337 malicious. The 100 pilot queries do not overlap these formal queries. We use Llama-3.3-70B (70.6B parameters, Q4\_K\_M), nomic-embed-text (137M, F16), temperature $0$, $K=3$, $k=3$, and a 32,768-token chat-context ceiling. The run records exact model digests, source/code hashes and Python 3.13.13; the server has two A800 80GB GPUs. Generator and verifier are separate calls to the same model. Historical labels are available to verification and the raw baseline, but target labels are used only after inference for scoring. The generator's first proposal receives only historical flow features.

The five conditions are raw flow retrieval, an unverified first reflection, VLEG, raw flow retrieval restricted to VLEG's admitted examples, and a single global summary of the labeled historical memory. All local conditions share a label-free raw-feature embedding retrieval pass and the same selected top-three candidates. A rejected candidate is dropped without replacement. The raw-on-admitted control therefore removes reflection content while retaining the same admission mask as VLEG. This shared raw retrieval deliberately differs from the reflection-driven formulation in Section III and tests consolidation/admission under controlled retrieval; it does not evaluate every component of the full formulation. Global-summary inference sees a corpus summary rather than the same top-three examples, and is a memory-architecture comparison rather than an equal-evidence modality ablation. These are controlled adaptations, not complete published Reflexion/HDR reproductions.

\textbf{Performance and trade-off.} Table~\ref{tab:exp6_performance} and Figure~\ref{fig:exp6_tradeoff} show that raw retrieval has the highest mean Macro-F1 among the evaluated conditions ($63.92\%$), while VLEG reaches $59.68\%$. VLEG increases attack recall from $71.39\%$ to $77.74\%$, but increases the false positive rate from $38.13\%$ to $48.78\%$. Its accuracy falls from $65.08\%$ to $59.74\%$. A post hoc always-benign reference has accuracy $66.30\%$, Macro-F1 $39.87\%$ and zero attack recall; this illustrates why accuracy alone is insufficient here. None of these conditions establishes deployment-quality intrusion detection, and no comparison against a trained conventional intrusion classifier is made.

Verification is beneficial relative to the unverified first-reflection condition: Macro-F1 improves by $17.02$ percentage points, and attack recall rises from $6.17\%$ to $77.74\%$. However, high admitted-memory coverage ($98.75\%$, 158/160 historical episodes) does not establish reliable cross-flow explanations. Raw-on-admitted retrieval nearly matches the raw baseline ($63.70\%$ versus $63.92\%$ Macro-F1), whereas adding the accepted reflections reduces its mean score to $59.68\%$. These comparisons are consistent with reflection content changing the decision trade-off; they do not establish a specific anchoring or causal-attribution mechanism. A subsequent deterministic explanation screen finds source-label agreement in 158/158 admitted VLEG reflections versus 84/160 first proposals. Explicit conjunctive conditions can be evaluated in 157/158 VLEG reflections; all 157 hold on their source flow, but 113 have at least one contrary-label match among the other archived historical draws. The remaining expression uses ambiguous $\gg$ syntax and is unresolved. The screen uses 160 unique historical flows and no test queries. It checks literal predicates, not natural-language causal validity, and the historical pool is neither independent nor representative. A human review with field-semantic judgments and adjudication remains incomplete.

\subsection{Limitations}
\label{sec:limitations}
Experiments 1--5 use small symbolic populations, while Experiment 6 evaluates a cleaned public-flow benchmark. The latter is a controlled adaptation with shared raw retrieval, not a production deployment or a complete validation of reflection-driven retrieval. Levels 1 and 2 evaluate seen combinations; Level 3 combines seen and withheld combinations. Their accuracy must not be interpreted as held-out network generalization. The flow experiment is restricted by deduplication/conflict exclusion, missing session metadata, one model and test partition, fixed method order and incomplete human explanation audits.

The synthetic rule is expressible as a single background-conditioned statement. It tests conditional rule learning, not an impossibility of global abstraction. The 7B and 70B comparisons also change model family and cannot isolate scale causally. Observed rank reversals and equal diagnostic rates are descriptive findings in these samples, not general superiority or equivalence claims.

Verification sees a known historical label and tests a candidate against one source episode. It can reject inconsistencies detected by the model, but agreement does not establish causal attribution or cross-episode validity. Reflection diagnostics based on known synthetic attributes cannot be transferred unchanged to natural traffic, where ground-truth explanations are generally unavailable.

Finally, the 7B figures are linked to the archived initial reimplementation snapshot, while updated 70B comparisons use the latest archived feedback-baseline revision. Stored item-level accuracies were independently recounted, but these historical files omit exact model digests and original verifier replies. Boolean type validation was also repaired in the oracle-audit parser; without original replies its historical impact cannot be quantified. Experiments 1--5 were not rerun, while Experiment 6 is independently audited against its archived predictions and frozen source. Context limits, quantization, model digests, CPU/GPU offloading and concurrent workloads require run-specific recording. The completed public-flow run records source/model/code hashes and hardware, but does not resolve every limitation of the historical experiments.

\section{Conclusions}
VLEG checks local reflections before memory admission and combines accepted reflections with source episodes during inference. In the reported symbolic experiments, refinement increases memory coverage and admitted reflections are more consistent with historical labels. Downstream benefits depend on the model and task: raw retrieval leads at 7B, while the latest archived 70B comparison gives a one-correct-evaluation pooled advantage to VLEG over raw retrieval. Hybrid grounding retains a disadvantage on some withheld combinations, and per-episode verification does not show a separate benefit for unsupported attribution.

The public-flow experiment strengthens this bounded interpretation. At 70B, VLEG improves Macro-F1 over unverified first reflections but is lower than raw retrieval, while increasing both attack recall and false alarms. High memory admission coverage therefore does not establish reliable cross-flow reasoning. Further work should test calibration and cross-episode validation on new, independently reserved data, complete explanation audits, and control timing/repeatability before making deployment claims. Historical symbolic files have now been inventoried against immutable 7B and 70B Git snapshots, and 48 stored item-level accuracy records reproduce their summaries. The latest feedback-baseline results replace stale 70B comparisons. Git provenance cannot recover missing model digests or raw verifier replies, so corrected-parser reruns and human review remain required.
